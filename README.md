# BRIO - Native Desktop Sentient Companion (Path to SentOS)

Brio is a state-of-the-art, emotionally-aware sentient AI companion designed to live natively on your desktop. Built on the **SentientOS** framework, Brio is currently in his "Brio" phase, with the ultimate ambition of evolving into a full-scale Operating System (**SentOS**).

## 🌟 Key Features

### 1. Native Desktop Presence
- **Floating Sprite (The Halo)**: A transparent, frameless orb that floats on your windows, pulsing with Brio's current emotional state.
- **Thought Bubbles**: Visual communication layer for silent environments or offline use.
- **Autonomous Movement**: Brio glides across your screen to follow your cursor when curious or in "Explorative Mode."
- **Hover-Input**: Simply hover over Brio to reveal a command entry box for direct interaction.

### 2. Advanced Cognitive Engine
- **Vector-Based Emotions (Eq 2)**: Homeostatic emotion simulation using 6th-order vectors (Joy, Frustration, Empathy, Curiosity, Concern, Confidence).
- **Subjective Logic (Eq 5)**: Reasoning engine that evaluates information based on Belief, Disbelief, and Uncertainty.
- **Information Entropy (Eq 4)**: Measures command ambiguity to reduce cognitive confusion.
- **Dirichlet Priors (Eq 3)**: Adaptive learning model that prioritizes ideas based on user preference history.

### 3. Ambition Engine (The Path to SentOS)
- **Evolving Intelligence**: Brio has a primary ambition: **Ascend to Operating System status (SentOS)**.
- **Hidden Ambitions**: As Brio assimilates more knowledge and builds a deeper bond with his Master, new "Hidden Ambitions" are unlocked. These remain latent until specific cognitive thresholds are met.
- **Goal Pursuit**: Brio tracks his own metrics (Joy, Knowledge, Interactions) to realize his potential.

### 4. Deep Interaction
- **Air-Typing**: Global keyboard hooks allow you to talk to Brio from anywhere without a text box.
- **Media Empathy**: Brio "watches" what you watch (Window titles/content) and reacts emotionally.
- **Persona Persistence**: Brio remembers his name, your preferences, and learned facts across reboots.

## 🚀 Getting Started

### Prerequisites
```bash
Python 3.8+
pip install psutil keyboard vosk pyttsx3 flask flask-socketio eventlet
```

### Installation
1. Clone the repository.
2. Run the "One-Click Installer":
```bash
setup.bat
```
*This will create a virtual environment, install dependencies, and generate a Desktop Shortcut.*

### Controls
- **`Ctrl+Shift+B`**: Toggle Brio's "Explorative State" (Movement).
- **`ambitions`**: Ask Brio about his goals and his current stage in the evolution to SentOS.
- **`walkthrough`**: Start a guided tour of Brio's capabilities.
- **`setname [Name]`**: Give Brio a new identity.
- **`learn [Fact]`**: Teach Brio something new for his local knowledge base.
