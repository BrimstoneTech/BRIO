# BRIO — Sentient AI Companion

> *"Don't Just See, Behold!"*

BRIO is an experimental AI that searches the web, reads pages, extracts knowledge, teaches itself, and quizzes itself to verify what it learned. Like sending an AI to school.

## Features

- 🔍 **Web Search** — Real DuckDuckGo search
- 📚 **Web Reading** — Reads pages and extracts key facts
- 🧠 **Autonomous Learning** — Self-directed curiosity loop every 10 minutes
- 📝 **Self-Assessment** — Generates quiz questions and tests itself
- 💬 **Chat** — Conversational AI with emotions and personality
- 🎨 **Living Orb** — Visual representation of BRIO's emotional state

## Chat Commands

| Command | What it does |
|---------|-------------|
| `search <query>` | Search the web |
| `learn about <topic>` | Read pages & memorize key facts |
| `start learning` | Enable autonomous curiosity |
| `stop learning` | Pause autonomous learning |
| `learning report` | See what BRIO has learned |
