# Brio's Knowledge Base

This folder is the **Library of Brio's Mind**. 
Any file you place here will be read, memorized, and used by Brio to answer your questions.

## How to Teach Brio
1. **Drop a File**: Place any `.txt`, `.md`, or `.pdf` file in this folder (or any sub-folder).
2. **Restart Brio**: Brio scans this folder every time he starts up.
3. **Ask**: Once loaded, you can ask Brio about the contents (e.g., "What does the Project Alpha document say?").

## Supported Formats
- **Text Files** (`.txt`): Best for notes, logs, and simple data.
- **Markdown** (`.md`): Best for structured documentation.
- **PDF** (`.pdf`): Brio can read standard PDF documents.

## Organization
You can create any sub-folders you like to organize your files. Brio reads everything recursively.
- `encyclopedias/`: Good for general knowledge or reference books.
- `personality/`: Defines Brio's core values and voice (Advanced).
- `conversations/`: Archives of past chats (auto-generated).
